# A To Z Exports — Brand Kit

Everything visual for the brand lives in this folder. Copy any file straight
into letterheads, packaging, invoices, presentations, or social profiles.

## Files

| File | Use |
|---|---|
| `a-to-z-mark.svg` | The emblem (wheat crest). Favicon, profile photos, stamps, small sizes |
| `a-to-z-logo-dark.svg` | Full lockup, forest-green text — light backgrounds, documents, print |
| `a-to-z-logo-light.svg` | Full lockup, ivory/gold text — dark backgrounds, website footer, video |

SVGs scale to any size without losing sharpness. To make a PNG (e.g. for
WhatsApp display picture): open the SVG in any browser → zoom → screenshot,
or use a free converter (cloudconvert.com) at 1024 px.

## Colours

- Deep forest green `#173D2B` — primary, backgrounds, text on light
- Muted gold `#C7A568` — emblem, rules, accents (light-gold highlight `#E6D3A8`)
- Warm ivory `#F8F6EF` — light backgrounds, text on dark
- Agricultural green `#42623A` — tagline on light backgrounds

## Rules

- Keep clear space around the logo (at least the height of the crest diamond).
- Never stretch, recolour, rotate, or add shadows/drop effects.
- Dark lockup on light backgrounds; light lockup on dark backgrounds — never
  the reverse.
- Minimum sizes: emblem 24 px digital / 8 mm print; full lockup 120 px / 30 mm.
